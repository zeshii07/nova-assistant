Nova Widget v29.0 Agent Persona

This page demonstrates the new v29.0 widget features: agent avatar (instead of message icon), pre-chat form, proactive greeting, and 4 position options.

What's new in v29.0:
1. Agent avatar (10 pre-built SVG portraits) replaces the message icon
2. Speech-bubble welcome message appears before chat opens
3. Pre-chat form (name + phone) captures lead info before chat starts
4. Proactive greeting auto-opens after 5 seconds (first visit only)
5. Four positions: bottom-right, bottom-left, bottom-center, side-panel

Try it live

Switch tenants and positions to see different agent personas and layouts. The widget reloads instantly.

v29.0 embed snippet

<script
  src="https://your-nova.com/widget.js"
  data-tenant="cleaning-demo"
  data-position="bottom-right"
  async>
