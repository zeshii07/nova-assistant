BUGFIXES IN THIS RELEASE
------------------------
  1. Widget form submit no longer reloads the page
     - Root cause: minimizeBtn/resetBtn were undeclared variables →
       ReferenceError in strict mode aborted mountWidget() before
       the form submit listener was attached
     - Fix: added minimizeBtn, resetBtn to the let declaration
     - Fix: Enter key handler now calls sendMessage() directly
       instead of dispatching a synthetic submit event
     - Fix: added type="button" to header buttons (prevent accidental
       form submission)

  2. Close button (✕) now works
     - Root cause: same as #1 — the close button listener was attached
       AFTER the ReferenceError, so it never ran
     - Fix: declaring the variables means the listener attaches correctly

  3. Notifications tab no longer throws "Cannot read properties of null"
     - Root cause: when notifications list is empty, the "Mark all as read"
       and "Refresh" buttons don't exist in the DOM, but the code tried
       to addEventListener on them unconditionally
     - Fix: null-check before addEventListener
     - Fix: added Refresh button to empty state
