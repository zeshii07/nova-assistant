WHAT'S NEW IN v30.1.4
---------------------
  1. WIDGET API KEY SECURITY (Issue 3: unauthorized use)
     - Tenants can now require an API key for widget requests
     - Set widget.apiKey in profile.json to require authorization
     - Set widget.allowedDomains to whitelist specific websites
     - Without the key, requests return 403 Forbidden
     - The widget reads the key from data-api-key attribute:
       <script src="..."
         data-tenant="cleaning-demo"
         data-api-key="sk_your_secret_key"
         async></script>
     - Open access (no key) is the default — opt-in security

  2. BYT CLEANERS DUBAI TENANT (permanent)
     - Created from cleaning-template
     - Agent: Maya (aria avatar)
     - Theme: sky blue (#0ea5e9)
     - Owner: owner@bytcleaners.ae
     - Tenant ID: byt-cleaners-dubai

  3. TENANT EXPORT FEATURE (Issue 1: tenants disappear on restart)
     - New endpoint: POST /api/admin/tenants/{id}/export
     - Returns all tenant files as JSON manifest
     - Use this to download tenant config from Render and commit to git
     - This solves the Render ephemeral filesystem issue

  4. CONNECTION FIX (v30.1.3 included)
     - Widget now uses data-server attribute to detect Nova URL
     - Better error messages with detected URL shown

ENABLING API KEY PROTECTION (optional, per-tenant)
---------------------------------------------------
To protect a tenant's widget from unauthorized embedding:

1. Edit tenants/{tenantId}/profile.json
2. Add to the "widget" block:
   "apiKey": "sk_your_secret_key_here",
   "allowedDomains": ["yourwebsite.com", "www.yourwebsite.com"]

3. Update the embed snippet on your website:
   <script src="https://nova-saas-test.onrender.com/widget.js"
     data-tenant="cleaning-demo"
     data-api-key="sk_your_secret_key_here"
     data-server="https://nova-saas-test.onrender.com"
     async></script>

4. Now only websites with the correct API key can use your widget.
   Other websites that try to embed it will get 403 Forbidden.

KEEPING TENANTS ON RENDER (preventing disappearance)
----------------------------------------------------
Render's free tier has an ephemeral filesystem. New tenants created
via the dashboard disappear on restart. To make them permanent:

1. Create the tenant via /admin → Onboard Business
2. Test it works
3. Export it: POST /api/admin/tenants/{id}/export
4. Save the returned files to your local nova-assistant/tenants/{id}/
5. git add -A && git commit && git push
6. Render redeploys with the tenant permanently in the repo
