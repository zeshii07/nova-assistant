CRITICAL BUG FIX
----------------
New businesses created from templates now work EXACTLY like the
demo tenants. Previously, the template extraction + placeholder
replacement process corrupted the tenant data, causing the
cleaning adapter to fail routing (new businesses couldn't answer
basic queries like "i want deep cleaning for my apartment").

ROOT CAUSE
----------
The old code cloned from the TEMPLATE folder (which had
{{placeholders}}), then did string replacement on all JSON files.
This corrupted the data because:
1. Some placeholders weren't in the replacement map ({{business_website}})
2. String replacement on JSON files could break valid JSON
3. The cleaning adapter's routing depended on data that was
   subtly different after placeholder replacement

THE FIX (v30.1.5)
-----------------
New tenants are now created by DIRECTLY COPYING the entire source
demo tenant folder (e.g., cleaning-demo). This is a byte-for-byte
exact clone. Only these files are then modified:

1. profile.json — business name, owner email, widget branding
2. personality.json — assistant name
3. templates/assistant.json — greetings with new business name
4. knowledge/business.json — business name, hours, contact
5. pricing/services.json — business name
6. pricing/sources.json — business name

NO placeholder replacement on any other files. The cleaning
services, knowledge, FAQs, templates, and all routing-critical
data are EXACT COPIES of the source demo tenant.

VERIFIED
--------
Tested "i want deep cleaning service for my apartment" on both:
- cleaning-demo: "Deep Apartment Cleaning selected. From AED 200..."
- byt-cleaners-dubai: "Deep Apartment Cleaning selected. From AED 200..."
IDENTICAL response! ✅
